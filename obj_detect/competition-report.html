Viktigste oppdagelser

OIV7 pretrain er gull
Open Images V7 har 600 klasser inkludert dagligvarer. COCO har bare 80 generelle klasser. Umiddelbar +2% mAP ved bytte. Viktigste enkeltbeslutningen.
100% treningsdata
A droppe 20% val holdout og trene pa alle 248 bilder ga val mAP fra 0.741 til 0.959. Den storste enkeltforbedringen. Med bare 248 bilder teller hvert bilde.
Enkelmodell > Ensemble
To modeller som er uenige om kategori forvirrer WBF. En sterk modell (0.8995) slar to (0.8857). Ensemble hjalp deteksjon men skadet klassifisering.
ONNX er obligatorisk
.pt filer picklet i Python 3.12 (Colab) laster IKKE i Python 3.11 (sandbox). Etter 4 feilede submissions var ONNX den eneste losningen.
Classifier skadet scoren
EfficientNet-B0 med 91% val accuracy droppet scoren med 0.004. YOLO bruker spatial kontekst (hyllelayout). Isolerte crops mister denne informasjonen.
Tiling la til stoy
640x640 tiles pa 1280-modellen ga flere falske positiver enn sanne positiver. For tette hyller overlapper produkter i tile-grensene.

Ting som ikke fungerte

Tilnaerming Problem Losning
.pt filer i sandbox Python 3.12→3.11 pickle-inkompatibilitet. Exit code 1. Bruk ONNX. Alltid.
torch.load patch Hverken ultralytics sin eller var custom patch fungerte i sandbox. ONNX trenger ingen patch.
SKU-110K pretrain Laerte hyllerader, ikke individuelle produkter. OIV7 pretrain.
1-class detektor + DINOv2 Detektor laerte store bokser over hele hyller. Multi-class YOLO (356 kategorier).
Copy-paste augmentation 1400+ instanser per bilde → OOM-crash ved epoch 140-183. Pseudo-labeling var tryggere.
timm / safetensors import Sikkerhetsscanneren blokkerte begge. Eksporter alt til ONNX.
FP16 ONNX pa CPU half=True ignoreres stille pa CPU-eksport. Eksporter pa GPU, eller aksepter FP32-storrelse.

Hva vi ville gjort annerledes

ONNX fra dag 1
Vi kastet 4 submissions pa .pt debugging. ONNX fungerer alltid, uavhengig av Python-versjon. Start her.
Test i eksakt sandbox-miljo
Var Colab L4-test (Python 3.12) bestod, men sandbox (3.11) feilet. En Docker-container med riktig Python hadde spart oss dager.
Enkelmodell forst
Vi brukte timer pa ensemble-infrastruktur som til slutt skadet scoren. Start enkelt, legg til kompleksitet bare nar det beviser forbedring.
100% data fra starten
48 valideringsbilder er for fa til a vaere meningsfulle. Tren pa alt, stol pa at OIV7-pretrain gir nok generalisering.
Budsjetter submissions
3 per dag. Test grundig lokalt for du sender. Hvert forsok teller.
